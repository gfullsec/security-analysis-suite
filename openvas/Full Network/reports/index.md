# Full Network – OpenVAS Reports

This directory contains the exported reports generated during the full-network vulnerability assessment.  
These reports include the results of the automated scan performed using **OpenVAS (Greenbone Community Edition)**.

---

## 📄 Available Reports

### **1. Baseline Full-Network Vulnerability Scan**
**File:** `full-network-baseline-vulnerability-scan-2026-09.pdf`  
**Description:**  
Comprehensive baseline report covering all active hosts in the network.  
Includes:  
- Medium and low-severity findings  
- TLS/SSL protocol issues  
- Timestamp disclosure findings  
- Per-host breakdown of detected vulnerabilities
