# WRT54G – OpenVAS Reports

This directory contains the reports generated during the vulnerability assessment of the **Linksys WRT54G** device.  
The reports include the output of the automated scan performed using **OpenVAS (Greenbone Community Edition)**, as well as any additional exports relevant to the analysis.

---

## 📄 Available Reports

### **1. Main OpenVAS Report**
**File:** `wrt54g-security-assessment-2026-09.pdf`  
**Description:**  
Comprehensive report generated using the **Full and Fast** scan profile, including:  
- vulnerability detection (CVEs)  
- analysis of exposed services  
- severity and impact classification  
- recommended remediation actions

## 🔎 Device Context

The Linksys WRT54G is a legacy SOHO router widely deployed in home networks.  
Due to its age and lack of vendor support, it commonly presents critical vulnerabilities related to outdated firmware, insecure protocols, and legacy configuration features.

This directory centralizes the results of the assessment for easy reference within the repository.
