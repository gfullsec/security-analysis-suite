# 📘 Security Analysis Suite

Este repositorio recopila los análisis de seguridad que realizo como parte de mi práctica y formación en ciberseguridad. Cada análisis se ejecuta en un entorno controlado y documentado, utilizando herramientas como OpenVAS, Lynis, Nmap y diversas técnicas de OSINT.

El objetivo del repositorio es:

- Mantener una colección organizada de auditorías y evaluaciones.  
- Documentar procedimientos reproducibles y buenas prácticas.  
- Servir como base técnica para mi GitHub Page.  
- Mostrar de forma clara y estructurada mi evolución y experiencia en seguridad.  

## 📂 Estructura del repositorio

- **openvas/** → Auditorías de vulnerabilidades con OpenVAS.  
- **lynis/** → Auditorías de sistemas Linux.  
- **nmap/** → Mapeo y análisis de redes.  
- **osint/** → Recolección de información con Shodan, FOFA y otras fuentes.  

Cada carpeta contiene:

- Informes en PDF.  
- Capturas de pantalla.  
- Diagramas del entorno.  
- Notas técnicas.  
- Conclusiones y recomendaciones.  

## 🔗 Integración con GitHub Page

Los análisis incluidos en este repositorio se enlazarán desde mi GitHub Page, donde se presentarán de forma resumida y ordenada para facilitar la lectura y navegación.
