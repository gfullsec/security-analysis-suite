# 📘 Security Analysis Suite
 
Repositorio dedicado a la documentación de auditorías de seguridad, proyectos de hardening y actividades realizadas en un entorno de laboratorio controlado.
 
El objetivo de este repositorio es:
 
- Documentar análisis y evaluaciones de seguridad de forma estructurada.
- Registrar procesos de hardening y remediación.
- Mantener evidencia técnica, informes y procedimientos reproducibles.
- Servir como soporte técnico para mi GitHub Pages y portfolio profesional.
- Mostrar mi evolución práctica en ciberseguridad defensiva.
 
## 📂 Estructura del repositorio
 
```text
security-analysis-suite/
│
├── openvas/
│
├── hardening/
│ ├── linux/
│ │ └── lynis/
│ ├── windows/
│ └── workstation-hardening-project/
│
└── lab-documentation/
```
 
### OpenVAS
 
Contiene auditorías de vulnerabilidades realizadas con OpenVAS, incluyendo informes, evidencias y documentación técnica asociada.
 
### Hardening
 
Documentación relacionada con el fortalecimiento de sistemas y la aplicación de medidas de seguridad.
 
- **linux/lynis/**: auditorías y evaluaciones de seguridad realizadas con Lynis.
- **windows/**: actividades de hardening y configuraciones de seguridad para sistemas Windows.
- **workstation-hardening-project/**: proyecto práctico de hardening sobre una estación de trabajo real, incluyendo evaluación, remediación y validación.
 
### Lab Documentation
 
Información relacionada con el laboratorio utilizado para las prácticas:
 
- Arquitectura y topología.
- Inventario de sistemas.
- Procedimientos y configuraciones.
- Diagramas y documentación de apoyo.
 
## 🔗 Integración con GitHub Pages
 
Los proyectos y análisis documentados en este repositorio se utilizan como soporte técnico para mi portfolio, proporcionando evidencias, metodología y documentación detallada de los trabajos realizados.
